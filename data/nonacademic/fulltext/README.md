# Non-academic text inputs

The local project contains 42 UTF-8 text files under `government`, `professional` and `media and news`. Filenames equal the inventory document filenames with the extension replaced by `.txt`. Content excludes added inventory headers and is processed as one block per file.

All 42 files are required and counted independently. Text files are excluded from Git. Public users must prepare their own copies from the inventory URLs; extraction and webpage changes may affect results. Missing inputs stop the runner before output replacement.
