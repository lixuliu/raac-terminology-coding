# Academic text inputs

The local project contains 231 UTF-8 files named `<record_id>.txt`, such as `#1.txt`, corresponding to metadata rows marked `full_text`. Pages are separated by exactly `\n\x0c\n` (newline, form feed, newline).

Text files are excluded from Git. Public users must obtain the documents and prepare files in this format. Different extraction tools or versions may change results. Missing required inputs stop the runner before output replacement.
